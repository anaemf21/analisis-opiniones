# Corpus anotado de sentimientos

Este repositorio contiene un pequeño corpus de reseñas de restaurantes en español, anotado manualmente con etiquetas de **sentimiento positivo**, **negativo** y **neutro**.

📂 Contenido:  
- `corpus_sentimientos.csv` → archivo con frases y su anotación.  

✍️ Objetivo:  
Ejemplo práctico de anotación lingüística para proyectos de Procesamiento de Lenguaje Natural (PLN).
